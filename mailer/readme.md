Spring Boot приложение с двумя модулями - Spring Mail и Spring Kafka.
С помощью Spring Kafka приложение подключается к Kafka и создает топик EMAIL_SENDING_TASKS, после чего подписывается на сообщения, поступающие от планировщика и бэкенд-сервиса.
