Планировщик #
Spring Boot приложение с двумя модулями - Spring Scheduler и Spring Kafka.

Задача сервиса - раз в сутки итерировать всех пользователей, и формировать для них отчёты о задачах и изменениях в них за сутки. Отчёт генерируется LLM через Summarization сервис

Планировщик является оркестратором данного процесса:

По расписанию находит всех пользователей, у которых есть сделанные за последние сутки задачи, и(или) остались несделанные
Для каждого пользователя генерируем отчёт, запросив его по Kafka RPC у Summarization сервиса
Сформированный отчёт, готовый к отправке, упаковываются в DTO и пересылается к сервис-рассыльщик писем через Kafka топик
